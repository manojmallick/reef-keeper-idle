# Reef Keeper Idle

Reef Keeper Idle is a browser-based aquarium idle game prototype. Collect coins, upgrade the tank, add fish, and observe passive income. The sponsor interaction is a local demo mechanic and does not connect to an advertising service.

## Run

```bash
pnpm install
pnpm dev
```

## Build

```bash
pnpm build
pnpm typecheck
```

Game logic is organized under `src/logic/`. No backend or external ad service is required.
